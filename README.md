# TapCard Standalone Demo

A framework-free TapCard digital business card demo ready for GitHub Pages.

## Live site

Once GitHub Pages is enabled with GitHub Actions as the source, the site will be available at:

`https://narvinsalesolan-star.github.io/Tap/`

## Files

- `index.html`
- `styles.css`
- `script.js`
- `.github/workflows/pages.yml`

## Features

- Responsive digital business card
- Call, email, and WhatsApp buttons
- Save contact as vCard
- Native share button with clipboard fallback
- Ready for HTTPS hosting through GitHub Pages

## Edit the profile

Replace the sample profile values inside `index.html` and `script.js`.
